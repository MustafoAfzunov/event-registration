## 2. What it was built with, and why

- **Tool:** Claude Code (Anthropic's agentic coding tool), in the Claude desktop app.
- **Models:** Claude Opus 5.5 (`claude-opus-5-5`) for phases 0-10; Claude Sonnet 5.5 (`claude-sonnet-5-5`) from 2026-10-12 13:44+06:00 for the manual-test run, the Stitch design work (phase 7b), the Chrome UI test, the requirements audit and this submission pack.
- **Why:** the assignment rewards proof over claims. An agent that can run the whole stack (Postgres, two browsers, a mailbox) can be made to show test output for every step, write the failing test first, and mutate the code to prove a test can fail. The strongest model was used for design and concurrency; a faster one for UI iteration.
- Also used: Stitch (Google) produced the visual design that phase 7b copied (item 7).
